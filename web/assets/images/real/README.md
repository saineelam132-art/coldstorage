# Your own photos (real, taken by the KoolKisaan team)

Put a photo here with **exactly** one of these names (.jpg, .jpeg, .png or .webp), then run

    python tools/photos.py
    python tools/export_static.py

Your photo then replaces the example photo or drawing everywhere on the site, captioned "Our …" with
"Photo: KoolKisaan team". The full list (with what is still missing) is in `web/assets/CREDITS.md`.
